# PICASO used in Kuss et al. (2026)

This repository contains the PICASO setup, input files, and analysis scripts used for the simulations presented in:

> Kuss et al. (2026), "Climates of temperate rocky planets with He-dominated atmospheres"

## Relevant files

### Input spectra
- spectrum_lhs_case1.txt
- spectrum_lhs_case2.txt
- spectrum_lhs_case3.txt

### Simulation setup
- create_pt_file_for_picaso.py
- trans_spectra.py

### Additional files
- patch_scipy.py

## Software version
The simulations were performed using PICASO v2.1.
